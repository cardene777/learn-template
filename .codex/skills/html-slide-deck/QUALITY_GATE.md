# Quality Gate

この文書は、スライドを完成扱いする前の不合格条件です。
1つでもFAILがある場合、HTML Viewerへ変換してはいけません。

## Reference Gate

新しいPage、Composition、Diagram、Explanationを追加する時は最初に判定します。

FAIL条件です。

- 参照PDFの近いページを1枚以上選んでいない。
- 参照PDFと新規Templateを横並びで確認していない。
- 参照PDFに根拠のないHub、Network、カードUIを採用している。
- 参照PDFよりBoxが多い。
- 参照PDFより色面が多い。
- 参照PDFより線が太い。
- 参照PDFより装飾が多い。
- 参照PDFより情報が中央へ密集している。
- 参照PDFと比べて片側だけ不自然な空白がある。
- 一般的なDiagramに見え、OWS資料の別ページに見えない。

Reference Gateは意味の正しさより先に確認します。
見た目がOWS参照PDFから離れている場合は、内容が正しくてもFAILです。

## Layout Gate

FAIL条件です。

- Main titleが44px未満。
- Body textが18px未満。
- 図中の主要Labelが18px未満。
- 主役図が存在しない。
- Architecture / Flow / Boundaryページで主役図が内容領域の50%未満。
- 要素の内部で上下左右の視覚中心が揃っていない。
- 意図しない空白がページ下半分に残っている。
- 同じ構図が3ページ連続している。
- タイトル強調帯がタイトル文字幅を超えている。
- タイトル強調帯がタイトル文字幅より短い。
- 見出しに読点`、`が入っている。

## Diagram Gate

FAIL条件です。

- 箱と矢印を置いただけで意味ラベルがない。
- 矢印が交差している。
- Trust Boundaryが文章だけで説明されている。
- Data Bindingが文章だけで説明されている。
- Flowページで時間順が視覚的に追えない。
- 図の主役がどこか分からない。
- 直線で済むArrowが折れている。
- 斜めArrowを一般的な関係図だからという理由だけで使っている。
- Nodeに丸角、強い影、グロー、太い色帯を使っている。
- 色付きカードを等間隔に並べただけになっている。
- すべての領域に機械的にハッチを使っている。
- Nodeの種類が違うのに同じカード部品で表現している。

## OWS Visual Grammar Gate

以下のうち対象ページに近い構図を選び、適合を確認します。

### Editorial Grid

- 同格要素をカードで囲んでいない。
- 上部の細い罫線、小ラベル、見出し、説明、具体例の順になっている。
- 各列の視覚重心が揃っている。

### Structured List + Notes

- 左側が構造化リストとして読める。
- 行区切りは細い線である。
- 右側の説明Boxは薄い枠である。
- 強調項目だけ色を使っている。

### Before / After Architecture

- 左右領域のサイズと上端が揃っている。
- BeforeとAfterで比較対象の位置が対応している。
- システム境界が破線などで明確に見える。
- 新規要素だけがハッチやGoldで強調されている。

### Sequence / Time Flow

- Actor、Lifeline、Step、Phaseの位置関係が整っている。
- RequestとResponseが別Stepである。
- Responseは破線である。
- 自己処理Arrowが次Stepと干渉していない。

## Content Gate

FAIL条件です。

- 1ページに2つ以上の大きな主張がある。
- 用語を並べただけで説明していない。
- 仕様上の事実と推測が混ざっている。
- Sourceにない内容を断定している。
- Summaryで本文の結論を回収していない。

## New Template Review

新規Templateは次の3つを同時に見せて確認します。

1. 参照PDFの近いページ。
2. 承認済み既存Template。
3. 新規Template。

確認項目です。

1. 背景色が近い。
2. 線幅が近い。
3. Boxの量が近い。
4. 色の量が近い。
5. 余白が近い。
6. ラベルの密度が近い。
7. 視覚重心が近い。
8. 同じ資料シリーズに見える。

新規Template単体だけを見て承認してはいけません。

## Montage Review

PDF生成後、全ページを1枚のMontageにして確認します。
Montageで以下を確認します。

1. 文字が小さく見えないか。
2. 下半分が空白だらけのページがないか。
3. 同じ構図が続いていないか。
4. 各ページに主役図があるか。
5. Page Patternが意図通り使い分けられているか。
6. 見出しサイズと余白が揃っているか。
7. 参照PDFと異なるデザイン体系のページが混ざっていないか。

## Viewer Gate

PDF Viewer HTML生成後に確認します。

1. サイドバーが常時表示される。
2. サムネイル画像だけにactive枠が付く。
3. 番号までactive枠で囲まない。
4. サムネイルをタップすると対応ページへ移動する。
5. active枠も対応ページへ移動する。
6. スマホ幅でも1、3、10、最終ページへ移動できる。
