# Left Visual Right Explanation

通常スライドのContent Regionを、左の図領域と右の説明領域に分ける構成パターンです。

## このパターンの位置づけ

これは説明テンプレートではありません。
あくまでスライド内部の大枠配置を定義するCompositionです。

## 固定構造

```text
Content Region
x=80 y=315 w=1440 h=505

┌──────────────────────────────┬─────────────────┐
│                              │                 │
│             図               │      説明       │
│                              │                 │
└──────────────────────────────┴─────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 左図領域 | `x=80`, `y=315`, `w=880`, `h=505` |
| 右説明領域 | `x=1008`, `y=315`, `w=512`, `h=505` |
| 左右ギャップ | `48` |
| 左内側領域 | `x=104`, `y=339`, `w=832`, `h=457` |
| 右内側領域 | `x=1032`, `y=339`, `w=464`, `h=457` |

## 変更してよいもの

- 左図領域の中身
- 右説明領域の中身

## 変更してはいけないもの

- Content Regionの外枠座標
- 左右領域の基準座標
- 左右ギャップ
- `PRIMARY VISUAL`のような領域ラベルを置くこと
- 右側を小さい複数ブロックへ分割すること
- 説明テンプレートの具体的な文字組みをここで固定すること
- 図を押し込むために文字を小さくすること
