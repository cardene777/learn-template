# Split Comparison

通常スライドのContent Regionを、左右2つの同じ大きさの領域に分ける構成パターンです。

## このパターンの位置づけ

これは比較説明テンプレートではありません。
あくまでスライド内部の大枠配置を定義するCompositionです。

## 固定構造

```text
Content Region
x=80 y=315 w=1440 h=505

┌─────────────────────┬─────────────────────┐
│                     │                     │
│       比較A         │       比較B         │
│                     │                     │
└─────────────────────┴─────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 左比較領域 | `x=80`, `y=315`, `w=696`, `h=505` |
| 右比較領域 | `x=824`, `y=315`, `w=696`, `h=505` |
| 左右ギャップ | `48` |
| 左内側領域 | `x=104`, `y=339`, `w=648`, `h=457` |
| 右内側領域 | `x=848`, `y=339`, `w=648`, `h=457` |

## 変更してはいけないもの

- Content Regionの外枠座標
- 左右領域の基準座標
- 左右ギャップ
- 左右の幅を変えること
- 片方だけに大きな情報量を入れること
