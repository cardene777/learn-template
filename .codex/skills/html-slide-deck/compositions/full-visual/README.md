# Full Visual

通常スライドのContent Region全体を、1つの図領域として使う構成パターンです。

## このパターンの位置づけ

これは図テンプレートではありません。
あくまでスライド内部の大枠配置を定義するCompositionです。

## 固定構造

```text
Content Region
x=80 y=315 w=1440 h=505

┌──────────────────────────────────────────────┐
│                                              │
│                    図                        │
│                                              │
└──────────────────────────────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 図領域 | `x=80`, `y=315`, `w=1440`, `h=505` |
| 内側領域 | `x=104`, `y=339`, `w=1392`, `h=457` |

## 使うべき時

- アーキテクチャ全体を見せる時。
- フローやシーケンスが横に長い時。
- 左右分割にすると図が窮屈になる時。
- 図そのものがページの主役になる時。

## 使わない時

- 図より説明が主役の時。
- 図の補足を同じページで長く書きたい時。
- 比較が主役の時。

## 変更してよいもの

- 図領域の中身

## 変更してはいけないもの

- Content Regionの外枠座標
- 内側領域の基準座標
- 説明領域を追加すること
- 図を押し込むために文字を小さくすること
