# Two Phase

通常スライドのContent Regionを、上段と下段の2つのフェーズ領域に分ける構成パターンです。

## このパターンの位置づけ

これはフロー図テンプレートではありません。
あくまでスライド内部の大枠配置を定義するCompositionです。

## 固定構造

```text
Content Region
x=80 y=315 w=1440 h=505

┌──────────────────────────────────────────────┐
│                  フェーズA                    │
├──────────────────────────────────────────────┤
│                  フェーズB                    │
└──────────────────────────────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 上段領域 | `x=80`, `y=315`, `w=1440`, `h=232` |
| 下段領域 | `x=80`, `y=588`, `w=1440`, `h=232` |
| 上下ギャップ | `41` |
| 上段内側領域 | `x=104`, `y=339`, `w=1392`, `h=184` |
| 下段内側領域 | `x=104`, `y=612`, `w=1392`, `h=184` |

## 使うべき時

- 接続フェーズと署名フェーズのように、処理を2段階で見せる時。
- 前段と後段で責務が変わる時。
- 時系列よりも段階の違いを強調したい時。

## 使わない時

- 3段階以上ある時。
- 単一の長いシーケンスを見せたい時。
- 左右比較が主役の時。

## 変更してはいけないもの

- Content Regionの外枠座標
- 上下領域の基準座標
- 上下ギャップ
- 3段以上に増やすこと
