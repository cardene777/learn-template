# Four Elements

通常スライドのContent Regionを、2×2の4要素領域に分ける構成パターンです。

## このパターンの位置づけ

これは説明テンプレートではありません。
あくまでスライド内部の大枠配置を定義するCompositionです。

## 固定構造

```text
Content Region
x=80 y=315 w=1440 h=505

┌─────────────────────┬─────────────────────┐
│       要素1         │       要素2         │
├─────────────────────┼─────────────────────┤
│       要素3         │       要素4         │
└─────────────────────┴─────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 要素1 | `x=80`, `y=315`, `w=696`, `h=232` |
| 要素2 | `x=824`, `y=315`, `w=696`, `h=232` |
| 要素3 | `x=80`, `y=588`, `w=696`, `h=232` |
| 要素4 | `x=824`, `y=588`, `w=696`, `h=232` |
| 左右ギャップ | `48` |
| 上下ギャップ | `41` |

## 使うべき時

- 4つの要素を同じ重みで整理する時。
- 原則、特徴、構成要素、判断軸を並べる時。
- 順序よりも並列性を強調したい時。

## 使わない時

- 1つの図を主役にしたい時。
- 要素数が3つ以下の時。
- 各要素に長い説明を入れたい時。

## 変更してはいけないもの

- Content Regionの外枠座標
- 2×2の基本構造
- 4要素のサイズを変えること
- ブロックごとに情報量を大きく変えること
