# Composition Patterns

この文書は、スライド本文の**領域分割だけ**を定義します。
図の種類、Actor数、矢印、Data Flowなどはここでは定義しません。
それらは`DIAGRAM_PATTERNS.md`で扱います。

OWS参照資料の外枠を基準に、すべての構成パターンで共通フレームを維持します。

## 固定フレーム

スライドは16:9、論理座標`1600 x 900`で作ります。
本文要素をWebレイアウトとして再flowさせず、固定座標を基準に配置します。

```text
1600 x 900

┌────────────────────────────────────────────────────────────┐
│ 上部メタ情報                                               │
│                                                            │
│ セクションラベル                                           │
│ タイトル                                                   │
│ リード文                                                   │
│                                                            │
│ ┌────────────────────────────────────────────────────────┐ │
│ │                                                        │ │
│ │                CONTENT REGION                          │ │
│ │                                                        │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ ────────────────────────────────────────────────────────── │
│ 章名 / ページ名                              01 / 20       │
└────────────────────────────────────────────────────────────┘
```

基準座標です。

| 要素 | 基準 |
|---|---|
| 外側左余白 | `80px` |
| 外側右余白 | `80px` |
| 上部メタ情報 | `x=80, y≈48` |
| セクションラベル | `x=80, y≈118` |
| タイトル | `x=80, y≈177` |
| リード文 | `x=80, y≈225` |
| Content Region | `x=80〜1520, y≈300〜790` |
| Footer区切り線 | `y≈820` |
| Footer | `y≈852` |

タイトル、リード、Footerの位置は原則として全ページで揃えます。
構成パターンによって変えるのは`Content Region`の分割だけです。

## C01 / Cover

用途です。

- 表紙。
- Section扉。
- 大きな主張だけを置くページ。

Content Regionは大きなタイトルと象徴Visualへ使います。
通常本文ページのTitle / Lead配置とは別テンプレートとして扱います。

```text
┌──────────────────────────────────────────────┐
│                                              │
│ {大タイトル}                  {象徴Visual}   │
│ {サブタイトル}                               │
│                                              │
└──────────────────────────────────────────────┘
```

## C02 / Primary Left + Secondary Right

左側を主役、右側を補助情報として使います。
OWS参照資料の「OWSとは」に近い構成です。

基準比率です。

- 左側Primary Regionは約`60%`。
- 右側Secondary Regionは約`34%`。
- 間のGapは約`6%`相当を確保します。
- 左右Regionの**上端と下端を完全に揃えます**。

```text
┌──────────────────────────────┬──────────────────┐
│                              │                  │
│          {主役}              │     {補助}       │
│                              │                  │
└──────────────────────────────┴──────────────────┘
```

### 選択基準

- 主役図が単独で理解できる。
- 補足説明も同時に見せたい。
- 主役側が複雑になりすぎない。

主役側にActorやBoundaryが増えて窮屈になる場合は`C04 / Full Width Primary`へ切り替えます。

## C03 / Primary Right + Secondary Left

`C02`の左右反転版です。
Visualの視線方向や前ページとの連続性から右側を主役にした方が自然な場合だけ使います。

```text
┌──────────────────┬──────────────────────────────┐
│                  │                              │
│      {補助}      │           {主役}             │
│                  │                              │
└──────────────────┴──────────────────────────────┘
```

## C04 / Full Width Primary

Content Region全体を1つの主役Visualへ割り当てます。
OWS参照資料の全体Architecture、Trust Boundary、Sequenceなどに対応します。

```text
┌──────────────────────────────────────────────┐
│                                              │
│                   {主役}                     │
│                                              │
└──────────────────────────────────────────────┘
```

### 選択基準

- Actorが3つ以上ある。
- Boundaryが2つ以上ある。
- 通信線が複数ある。
- 小さな右説明欄を作ると主役図が窮屈になる。

複雑な図を無理に`C02`へ押し込んではいけません。

## C05 / Equal Split

Content Regionを左右ほぼ50:50で分割します。
Before / After、採用 / 不採用、方式A / 方式Bなどに使います。

```text
┌──────────────────────┬──────────────────────┐
│                      │                      │
│         {A}          │         {B}          │
│                      │                      │
└──────────────────────┴──────────────────────┘
```

左右の上端、下端、内部余白、見出し位置は必ず揃えます。
比較対象のVisual Scaleも極端に変えません。

## C06 / Top + Bottom

Content Regionを上下2段へ分割します。
OWS参照資料の接続フェーズ / 署名フェーズに近い構成です。

```text
{上段ラベル}
┌──────────────────────────────────────────────┐
│                    {上段}                    │
└──────────────────────────────────────────────┘
────────────────────────────────────────────────
{下段ラベル}
┌──────────────────────────────────────────────┐
│                    {下段}                    │
└──────────────────────────────────────────────┘
```

上段と下段は同じ幅にし、左右端を揃えます。
高さは内容により変えて構いませんが、意味のない数px単位のズレを作りません。

## C07 / Three Columns

3つの同格要素を横並びにします。

```text
┌──────────────┬──────────────┬──────────────┐
│   {要素1}    │   {要素2}    │   {要素3}    │
└──────────────┴──────────────┴──────────────┘
```

3つが本当に同格の場合だけ使います。
主役と補助の関係がある場合は`C02`または`C03`を使います。

## C08 / Four Columns

4つの同格要素を横並びにします。
OWS参照資料の4つの特徴、4本柱のようなページに対応します。

```text
┌──────────┬──────────┬──────────┬──────────┐
│ {要素1}  │ {要素2}  │ {要素3}  │ {要素4}  │
└──────────┴──────────┴──────────┴──────────┘
```

各列のWidth、Top、Bottomを揃えます。
ただし内部Visualまで同じ形にする必要はありません。

## C09 / Two by Two

4つの要素を2x2で配置します。
横4列では文字やVisualが小さくなりすぎる場合に使います。

```text
┌──────────────────┬──────────────────┐
│      {要素1}     │      {要素2}     │
├──────────────────┼──────────────────┤
│      {要素3}     │      {要素4}     │
└──────────────────┴──────────────────┘
```

## C10 / Primary + Conclusion Strip

主役領域の下に、ページの結論を強く固定する帯を置きます。

```text
┌──────────────────────────────────────────────┐
│                                              │
│                   {主役}                     │
│                                              │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│                 {結論・原則}                 │
└──────────────────────────────────────────────┘
```

結論Stripは追加説明欄ではありません。
ページから持ち帰る1文を固定するために使います。

## Composition選択ルール

1. 先にページの`message`と`primary visual`を決めます。
2. その後でCompositionを選びます。
3. 図の都合でCompositionを歪めません。
4. Content Region内の要素数が増えて窮屈になった場合は、より広いCompositionへ切り替えます。
5. `C02`へ複雑なArchitectureを詰め込まず、`C04`へ切り替えます。
6. 比較対象でないものを`C05`へ置きません。
7. 3〜4要素が同格でない場合、Column Patternを使いません。
8. 各RegionのTop / Bottom / Center Lineは数値で管理し、目視だけで揃えません。

## CompositionとDiagramの責務分離

Compositionは「どこに置くか」だけを決めます。
Diagram Patternは「その領域の中で何をどう描くか」を決めます。

```text
Slide
├── Fixed Frame
├── Composition Pattern
│   ├── Primary Region
│   ├── Secondary Region
│   └── Conclusion Region
└── Diagram Pattern
    └── Region内部へ配置
```

同じ`C02 / Primary Left + Secondary Right`でも、Primary RegionにはHub Diagram、Before / After Diagram、Trust Boundary Diagramなど異なる図を入れられます。
