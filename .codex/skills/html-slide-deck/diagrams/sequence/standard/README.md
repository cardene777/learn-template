# Standard Sequence

OWS参照資料の後半にあるシーケンス図を基準にした標準シーケンス図です。

## 位置づけ

- `Diagram`カテゴリのテンプレートです。
- 通常スライドの共通フレームに載せて使用します。
- 独立した「規格」列は標準では持ちません。シーケンス図の主役であるActorと矢印の横幅を優先します。

## 構造

```text
フェーズ | 手順 | Actor / Lifeline / Message
```

フェーズ列が不要な場合は省略できます。

## レイアウトルール

- スライドは`1600×900`固定です。
- 共通スライドフレームは以下を維持します。
  - 左ヘッダー `{章番号} ／ {セクション名}`
  - 右ヘッダー `{ページ番号} / {総ページ数}`
  - 上罫線 `y=100`
  - タイトル `x=80`付近
  - リード `y=265`
  - Content Region `x=80, y=315, w=1440, h=505`
- タイトルの金色強調帯は文字そのものの背景として描画し、タイトル文字幅に追従させます。
- 図全体はContent Region内で上下中央に寄せます。
- フェーズ列の幅はフェーズ名の長さに応じて調整します。
- 手順列の幅は最長の手順文に応じて調整します。
- Actorヘッダー幅はActor名に応じて調整します。
- Actor下の補足説明は標準では表示しません。

## 矢印ルール

- Requestは赤系の実線です。
- Responseは赤系の破線です。
- 決済・署名系は緑系です。
- 矢印はライフライン中心からライフライン中心へ水平に引きます。
- Actor幅や間隔が変わった場合も、矢印の始点・終点はライフライン中心へ追従させます。
- 同一Actor内の処理は小さな折り返し矢印で表現します。
- 自処理矢印の直後は通常より行間を広げ、上下の矢印が詰まりすぎないようにします。

## 規格情報

A2A / UCP / MPP / OWSなどの規格情報を主題として見せたい場合は、標準テンプレートへ無理に追加せず、規格列ありの派生テンプレートを別途用意します。
