# Template Refinement Checklist

新規テンプレートやサンプルを見せる前に必ず使う整列確認リストです。

## 目的

初回案で終わらせず、参照PDFと同じ資料シリーズに見えるまで整えます。

## 必須確認

1. 参照PDFの近いページを1枚以上選びます。
   - 近いページが見つからない場合は、まず参照PDF内の構図分類を追加します。
2. Section Label、Title、Lead、Content、Footerの縦位置を確認します。
   - 独自の縦位置へずらしません。
3. TitleとSection Labelの重なりを確認します。
   - Titleの強調帯がSection Labelへ近すぎる場合はFAILです。
4. Content Region内の上端と下端を揃えます。
   - 各Panel、Column、Zoneの開始Yと終了Yを数値で揃えます。
5. 文字の実表示を確認します。
   - SVG textで長文を1行にしません。
   - 長文は手動で行分けします。
   - Box外へはみ出す文字がある場合はFAILです。
6. Arrowの接続を確認します。
   - ArrowheadがBoxへ食い込む場合はFAILです。
   - 直線で済むArrowが折れている場合はFAILです。
7. 余白を確認します。
   - 片側だけ空きすぎている場合はFAILです。
   - 下側だけ空きすぎている場合はFAILです。
8. 色量を確認します。
   - 参照PDFより色面が多い場合はFAILです。
   - 新規要素だけGoldまたはハッチで示します。
9. 比較表示を作ります。
   - 参照PDF、承認済みTemplate、新規Templateを横並びで確認します。
10. 最終ファイル名にdraftを付けます。
   - ユーザー承認前に正式なtemplate.htmlへ追加しません。

## 禁止

- 初回生成HTMLをそのまま完成扱いすること。
- 目視確認なしで完成扱いすること。
- 文字が崩れたままユーザーへ見せること。
- 参照PDFにない図法を一般論で採用すること。
- 汎用カードUIとして整えること。
