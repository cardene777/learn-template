# Section Grid

OWS参照資料の目次ページに合わせた、最大9セクションのグリッド型目次パターンです。

## 用途

章立てが1〜9個ある資料の目次に使います。
目次は原則1ページにまとめます。

## 固定構造

```text
1600 × 900

┌──────────────────────────────────────────────┐
│ 00 ／ {セクション名}                 {ページ番号} / {総ページ数} │
│ ──────────────────────────────────────────── │
│ 00  目次                                     │
│ 目次                                         │
│                                              │
│ 01 / pages     02 / pages     03 / pages     │
│ title          title          title          │
│ desc           desc           desc           │
│                                              │
│ 04 / pages     05 / pages     06 / pages     │
│ title          title          title          │
│ desc           desc           desc           │
│                                              │
│ 07 / pages     08 / pages     09 / pages     │
│ title          title          title          │
│ desc           desc           desc           │
└──────────────────────────────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 左ヘッダー | `x=80`, baseline `y=72` |
| 右ヘッダー | `x=1520`, baseline `y=72`, 右揃え |
| ヘッダー区切り線 | `x=80..1520`, `y=100` |
| 小番号 | `x=80`, baseline `y=180` |
| 小ラベル | `x=132`, baseline `y=180` |
| 大タイトル | `x=80`, baseline `y=265` |
| 1段目 | baseline `y=340` |
| 2段目 | baseline `y=510` |
| 3段目 | baseline `y=680` |
| 左列 | `x=80` |
| 中央列 | `x=585` |
| 右列 | `x=1090` |

## ヘッダー規則

- 左ヘッダーは`{章番号} ／ {セクション名}`です。
- 右ヘッダーは`{ページ番号} / {総ページ数}`です。
- `{資料名}`は置きません。
- Footerは置きません。
- 上部区切り線は残します。

## 文字制約

- セクションタイトルは1行だけです。
- 説明文は1行だけです。
- 説明文は20文字程度を上限にします。
- 説明を2行にしたい場合は、項目数を6個以下にして6項目版を別パターンとして作ります。
- 文字サイズを下げて無理に長文を入れてはいけません。
- 隣の列へ侵入する説明文は禁止です。

## 9章を超える場合

- 10章以上はこのパターンへ詰め込まない。
- 目次を2ページに分割するか、`vertical-list`など別パターンを追加します。

## 変更してよいもの

- `{章番号}`
- `{セクション名}`
- `{ページ番号}`
- `{総ページ数}`
- `{番号01}`から`{番号09}`
- `{ページ範囲01}`から`{ページ範囲09}`
- `{セクションタイトル01}`から`{セクションタイトル09}`
- `{説明01}`から`{説明09}`

## 変更してはいけないもの

- 1600×900の論理座標
- 3列×3段の基本構造
- 1ページ最大9項目の制限
- セクションブロックの左端位置
- ヘッダーの基準位置
- 大タイトルの基準位置
- 説明文を2行以上にすること
- Footerを追加すること
- 資料名を追加すること
- カード枠や強い背景色を追加すること
