# Header Title Lead

通常スライドで使用する標準の大枠構成です。
このパターンは、Content Regionの中身ではなく、スライド全体の共通フレームだけを定義します。

## ファイル

- `template.html`
  - プレースホルダーだけを持つ再利用テンプレートです。
- `example.html`
  - 実際の文字を入れ、完成時の見え方を確認するサンプルです。
- `README.md`
  - この大枠の用途、固定座標、変更可能範囲を定義します。

## 用途

通常の説明スライド、図解スライド、比較スライドなどの共通外枠として使います。
表紙、目次、章扉には使用しません。

## 固定構造

```text
1600 × 900

┌──────────────────────────────────────────────┐
│ {章番号} ／ {セクション名}      {ページ番号} / {総ページ数} │
│ ──────────────────────────────────────────── │
│                                              │
│ {タイトル}                                   │
│ ━━━━━  ← タイトル下部に重なる金系の強調帯   │
│                                              │
│ {リード文}                                   │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │              CONTENT REGION              │ │
│ │     Compositionはこの中だけを使用する    │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

## 固定座標

論理座標は`1600 x 900`です。

| 要素 | 座標・サイズ |
| --- | --- |
| 左右Safe Area | `x=80`から`x=1520` |
| 左ヘッダー | `x=80`, baseline `y=72` |
| 右ヘッダー | `x=1520`, baseline `y=72`, 右揃え |
| ヘッダー区切り線 | `x=80..1520`, `y=100` |
| タイトル | `x=80`, baseline `y=185` |
| タイトル強調帯 | `x=80`, `y=169`, `h=34` |
| リード文 | `x=80`, baseline `y=265` |
| Content Region | `x=80`, `y=315`, `w=1440`, `h=505` |

## タイトル強調帯

- 強調帯はタイトル文字の下部へ重ねます。
- 左端はタイトルと同じ`x=80`です。
- 高さは`34`を基準にします。
- 幅は固定値にしません。実際にレンダリングしたタイトルの幅に収まるように調整します。
- タイトル幅を超えて右へはみ出してはいけません。
- 標準色はOWS参照スタイルの金系`#d9c795`です。
- 強調帯を変更しても、タイトル文字の座標は動かしません。

## ヘッダー

- 左は`{章番号} ／ {セクション名}`です。
- 右は`{ページ番号} / {総ページ数}`です。
- `{資料名}`は置きません。
- Footerは置きません。ページ情報を上下で重複させないためです。

## リード文

- タイトル直下に、このページで伝える要点を1〜2文で置きます。
- 原則として2行以内に収めます。
- リード文を長くしてContent Regionを下へ押してはいけません。

## Content Region

- Compositionが使用できる範囲は`x=80, y=315, w=1440, h=505`です。
- Compositionはヘッダー、タイトル、強調帯、リード文の座標を変更してはいけません。
- `template.html`内の斜線、破線、`{CONTENT REGION}`は領域確認用です。完成スライドではCompositionの内容へ置き換えます。

## 変更してよいもの

- `{章番号}`
- `{セクション名}`
- `{ページ番号}`
- `{総ページ数}`
- `{タイトル}`
- `{リード文}`
- タイトル強調帯の幅
- Content Region内部

## 変更してはいけないもの

- 1600×900の論理座標
- Safe Area
- ヘッダーの基準位置
- タイトルの基準位置
- リード文の基準位置
- Content Regionの外枠座標
- Footerを追加すること
- 資料名を追加すること

## Compositionとの関係

```text
Page
└── header-title-lead
    └── Content Region
        └── Composition
            ├── Diagram
            └── Explanation
```

このREADMEと`template.html`が矛盾する時は、レンダリング確認済みの`template.html`を優先し、README側を修正します。
