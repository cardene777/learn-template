# Title Only

OWS参照資料の章扉に合わせた、章番号と章タイトルを主役にする章扉パターンです。

## 用途

章の開始位置を明確に切り替えるために使います。
表紙、目次、通常スライドには使いません。

## 固定構造

```text
1600 × 900

┌──────────────────────────────────────────────┐
│ {章番号} ／ {セクション名}          {ページ番号} / {総ページ数} │
│ ──────────────────────────────────────────── │
│                                              │
│ {章番号}                                     │
│                                              │
│ {章タイトル}                                 │
│ ━━━━━                                        │
│                                              │
│ {章の要点を1文で示すリード文}                │
│ {この章で扱う範囲を短く補足する文}           │
└──────────────────────────────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 左ヘッダー | `x=80`, baseline `y=72` |
| 右ヘッダー | `x=1520`, baseline `y=72`, 右揃え |
| ヘッダー区切り線 | `x=80..1520`, `y=100` |
| 章番号強調帯 | `x=80`, `y=291`, `w=120`, `h=30` |
| 章番号 | `x=80`, baseline `y=315` |
| 章タイトル | `x=80`, baseline `y=440` |
| 短い罫線 | `x=80..230`, `y=505` |
| リード文 | `x=80`, baseline `y=590` |
| 補足文 | `x=80`, baseline `y=634` |

## ヘッダー規則

- 左ヘッダーは`{章番号} ／ {セクション名}`です。
- 右ヘッダーは`{ページ番号} / {総ページ数}`です。
- `{資料名}`は置きません。
- Footerは置きません。
- 上部区切り線は残します。

## 章番号強調帯

- 章番号文字の下部にだけ重なる短い金系の強調帯です。
- 章番号より大きく右へ伸ばしてはいけません。
- 標準は`x=80`, `y=291`, `w=120`, `h=30`です。

## 文字制約

- 章タイトルは原則1行です。
- リード文は1行だけです。
- 補足文も1行だけです。
- 文字が長い時は文字サイズを小さくせず、文言を短くします。

## 変更してよいもの

- `{章番号}`
- `{セクション名}`
- `{ページ番号}`
- `{総ページ数}`
- `{章タイトル}`
- `{章の要点を1文で示すリード文}`
- `{この章で扱う範囲を短く補足する文}`

## 変更してはいけないもの

- 1600×900の論理座標
- ヘッダーの基準位置
- 章タイトルの左端`x=80`
- 章タイトルの基準位置
- Footerを追加すること
- 資料名を追加すること
- 図や説明カードを追加すること
