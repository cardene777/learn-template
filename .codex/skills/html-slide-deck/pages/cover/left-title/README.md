# Left Title

OWS参照資料の表紙に合わせた左寄せタイトル型の表紙パターンです。

## 用途

技術資料、提案資料、設計資料の表紙に使います。
表紙専用のため、通常スライド、目次、章扉には使いません。

## 固定構造

```text
1600 × 900

┌──────────────────────────────────────────────┐
│                                  {ページ番号} ／ {総ページ数} │
│                                              │
│ {タイトル上段}                               │
│ {タイトル下段}                               │
│ ━━━━━                                        │
│                                              │
│ {説明文1}                                    │
│ {説明文2}                                    │
└──────────────────────────────────────────────┘
```

## 固定座標

| 要素 | 座標・サイズ |
| --- | --- |
| 右上ページ情報 | `x=1520`, baseline `y=76`, 右揃え |
| タイトル上段 | `x=80`, baseline `y=335` |
| タイトル下段 | `x=80`, baseline `y=455` |
| 短い罫線 | `x=80..180`, `y=525` |
| 説明文1 | `x=80`, baseline `y=618` |
| 説明文2 | `x=80`, baseline `y=662` |

## 文字スタイル

- タイトル上段は黒にします。
- タイトル下段はOWS参照スタイルの金系にします。
- タイトルは原則2行以内にします。
- 説明文は2行以内にします。
- 資料種別やキーワード行は置きません。

## 変更してよいもの

- `{ページ番号}`
- `{総ページ数}`
- `{タイトル上段}`
- `{タイトル下段}`
- `{説明文1}`
- `{説明文2}`

## 変更してはいけないもの

- 1600×900の論理座標
- 右上ページ情報の基準位置
- タイトルの左端`x=80`
- タイトル上段と下段の縦位置
- 説明文の基準位置
- 資料種別を追加すること
- キーワード行を追加すること
- Footerを追加すること
- Content Regionを追加すること
